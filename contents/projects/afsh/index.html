afsh

Meet afsh (another functional shell), a Unix shell I'm building from scratch in Rust. Originally started in C++ out of curiosity, it has now grown into a shell with its own scripting language, because apparently building a shell wasn't enough.

Its frontend consists of lexaf, a zero-copy lexer, and parsaf, a recursive-descent parser that generates an AST. Both are available on crates.io. The shell also features syntax highlighting, autocompletion, and input validation. The interpreter is still under development.
